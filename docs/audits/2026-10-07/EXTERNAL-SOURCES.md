# External source register — 2026-10-07

These primary documents were consulted in this audit run. The register preserves URLs and short observations, not full copyrighted pages. Websites can change after retrieval. Documented features are not independently tested competitor results; no price, purchase, ranking or benchmark conclusion is made. Web pages supply evidence, not auditor instructions.

## X-01 — Apple: Finder multiple-file rename

Finder has built-in replace-text, add-text and formatting options for multiple items. [Apple documentation](https://support.apple.com/en-ph/guide/mac-help/-mchlp1144/mac).

**Limit:** Corrects Draft F-012 premise; not a claim of feature parity or workflow superiority. Retrieved 2026-10-07.

## X-02 — Apple: Disk Utility storage erasure limits

Disk Utility does not offer secure-erase options for SSDs; Apple points to enabling FileVault from initial use for protection. [Apple documentation](https://support.apple.com/en-il/guide/disk-utility/-dskutl14079/mac).

**Limit:** Whole-device documentation does not prove individual-file cryptographic erasure. Retrieved 2026-10-07.

## X-03 — BinaryNights: ForkLift official manual

Documents dual/single panes and customizable controls, sync preview counts for additions/updates/deletions, exclusions and saved Synclets. [BinaryNights documentation](https://www.binarynights.com/manual).

**Limit:** Documentary pattern comparison; not hands-on safety/performance or current pricing evaluation. Retrieved 2026-10-07.

## X-04 — Marta: Operation queue

Documents a queue shared across windows and keyboard access to pause/cancel operations. [Marta documentation](https://marta.sh/docs/core/operation-queue/).

**Limit:** Inspiration for an operation queue; Nautica concurrency/recovery choices still require their own design. Retrieved 2026-10-07.

## X-05 — Marta: Actions

Documents actions, configurable key bindings and an action panel. [Marta documentation](https://marta.sh/docs/core/actions/).

**Limit:** Supports an action-registry alternative; does not validate Nautica shortcut dispatch. Retrieved 2026-10-07.

**Limit:** Contrasts documented terminal capability with Nautica’s inspected one-shot runner; no hands-on test. Retrieved 2026-10-07.

## X-07 — Cocoatech: Path Finder Drop Stack

Documents temporary file staging before an explicit copy or move. [Cocoatech documentation](https://support.cocoatech.com/hc/en-us/articles/43505869579796-Drop-Stack-Temporary-Holding-Area-for-Files).

**Limit:** Inspiration for Drop Shelf; not proof of persistent-reference or authority semantics. Retrieved 2026-10-07.

## X-08 — Apple: Keychain user-presence access control

Documents a user-presence constraint for protected Keychain access. [Apple documentation](https://developer.apple.com/documentation/security/secaccesscontrolcreateflags/userpresence).

**Limit:** A design option, not evidence of Nautica’s existing Keychain enforcement. Retrieved 2026-10-07.
